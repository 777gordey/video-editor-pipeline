# brand/

Royalty-free assets only (no AI-generated scenes, no copyrighted tracks).

- `plates/` - background plates (`*.mp4`, vertical preferred). A file whose name contains the version
  id (`v2`, `v3`, `v5`) is used for that version; otherwise plates come from the Pexels API.
- `music/` - music beds (`*.mp3|wav|m4a`). If empty the engine falls back to `assets/music` and then to a
  synthesized placeholder beat. Add a license note next to every file you add.
