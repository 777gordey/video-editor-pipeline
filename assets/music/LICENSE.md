# Источник

Все треки скачаны с [Mixkit](https://mixkit.co/free-stock-music/) вручную
одним разом (24.09.2026) — Pixabay не имеет публичного Music/Audio API
(только Images/Videos, см. `scripts/audio_mix.py`), поэтому для фоновой
музыки применён тот же принцип, что и для звуков punch-in: небольшой набор
файлов, зашитый в репозиторий.
